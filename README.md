# Thomas Hervey

Geospatial product engineer. PhD in geography (spatial cognition, geographic information retrieval). Four and a half years on ArcGIS Hub, working on search and discovery, mapping, downloads, ETL and data interoperability APIs, from engineer to product owner.

I build tools that test how well people and models reason about places.

## Current work

- **[Spatial Eval](https://cloud-native-geo-tutorial.thomashervey.net/spatial-eval)**: a benchmark of how well LLMs draw San Francisco neighborhood boundaries, scored against SF Planning polygons. Models do best where the reference sources already agree with each other, and high stated confidence did not mean a better answer.
- **[Scout Lab](https://cloud-native-geo-tutorial.thomashervey.net/scout/lab)**: compares stuffing, RAG and agent modes on natural-language geospatial queries, plus a styling agent. Recorded demo is public; live runs are admin-only.
- **[Cloud-Native Geo modules](https://cloud-native-geo-tutorial.thomashervey.net/cng-modules)**: hands-on learning notes on GeoParquet, PMTiles, COG, STAC, DuckDB and PostGIS.
- **[Truer Size](https://truer-size.vercel.app)**: bearing-based tool for comparing the real size of places on Web Mercator.

**Code:** [cloud-native-geo-showcase](https://github.com/thomas-hervey/cloud-native-geo-showcase), a read-only snapshot of the app, exercises and eval pipeline.
